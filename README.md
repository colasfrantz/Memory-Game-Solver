# Memory-Game-Solver

Project: 
To create a solver for the game of Memory using several different algorithmic strategies: Purely random, turning over an unknown card and forming a pair as soon as a known card is found, and investigating whether other strategies exist.

___________________________________________________________________________________________________________________________________________________________________________________________________

Create an interface that displays the game of Memory being played by the algorithm

___________________________________________________________________________________________________________________________________________________________________________________________________

Build a simulator that plays tens of thousands of games per strategy and per board size, then outputs the average number of moves and a graph showing ‘average moves as a function of the number of pairs’ for each strategy.
